# 多市場本機版開始使用

本機工程驗收已完成；實作版本bf5141e，45項本機驗收與5項待外部驗證，詳細證據見[EVIDENCE.md](EVIDENCE.md)。本次沒有登入券商或操作真實資產。

安裝版：在 Windows 開始功能表的「Mark Auto」資料夾開啟「Mark Auto 多市場平台」，不需輸入命令。
首次預設為本機模擬，資料另存於 `%LOCALAPPDATA%\MarkAuto-v2\local`；之後會恢復原有 v2 環境設定，啟動不會自動登入券商。
後續 AI 整合版中，一般「Mark Auto」與「Mark Auto 多市場平台」入口開啟同一個「多市場與 AI 研究平台」視窗。標準安裝包未內含選用的券商 SDK；本機模擬可正常操作，實際券商連接仍須另行準備並驗證。

本機可攜包：完整解壓縮後，雙擊旁邊的「開啟多市場平台.cmd」。資料保存在同一層的 `Data/platform-v2`。
原研究資料、設定與 ChatGPT 登入保留原位；研究頁面在同一個視窗內開啟，不搬移或合併研究與交易帳簿。

## AI 研究與 ChatGPT

頂部 ChatGPT 按鈕顯示原連線狀態，點選後可直接管理登入、模型及額度。沿用原已保存登入，不需要重新輸入或複製金鑰。

「策略」的「AI 策略研究」保留找策略點子、AI 研究、自訂規則與 Walk-forward；「AI 研究助理」直接進入原唯讀助理。助理的模型清單、研究引用、權限與每次連線同意仍由原控制器管理。

研究資料匯入與圖表在「市場」，原回測與結果比較在「績效」，研究偏好與備份在「設定」，均在同一視窗。左側同一工作區再次點擊或「返回多市場工作區」可回到平台頁面。

研究候選不會自動部署、送單或成為其他市場／持有政策的研究證據。研究與交易的停止操作分開；上方「取消研究作業」不送出多市場撤單或平倉，已消耗研究額度不退回。關閉介面需等原研究與助理安全收尾，背景交易引擎仍使用獨立關閉入口。

## 先做現股跨日模擬

1. 在「總覽」建立策略。先選台股現股、做多、持有3至5個交易日。
2. 選擇明確商品與本機帳戶，核對配置金額和2%示範風險。
3. 在「策略」選取草案，依序驗證規則、執行研究、檢查部署摘要並部署。
4. 在「交易」對帳，確認異常已處理，再明確恢復新倉。
5. 回到「總覽」按「推進一個模擬交易日」，檢查進場、持有天數及到期退出。
6. 在「交易」查看委託與可退出數量，在「績效」查看已實現、未實現、成本及已記錄估值回撤。

首次成交日是第0日。沒有當沖資格時，當日新買股票可能無法合法賣出；畫面會顯示可退出數量與受阻狀態。
合法且可執行的保護退出不會被正常最短持有期限阻擋。

預設總預算十萬元，股票六萬元、期貨四萬元，共用總額。單筆2%是本機範例，3%需要明確選擇；每日虧損上限10%。
風險估計包含成本、滑價及既有預留，不能保證實際損失不超過估計。

## 其他市場與持有政策

同一流程可選台指期與個股期貨，須選具體月份合約。這些本機示範規格、行情、資金與日曆都有明確來源標示，不能當成券商提供的真實資料。
當沖、3至5個交易日、約一週、長期及自訂持有政策有各自規則；夜盤執行預設關閉。
切換策略會建立新版本，既有部位保留原政策；部位移交必須另外預覽並確認範圍。

## 停止與關閉的差別

- 停止新倉並撤進場單：停止新增曝險，保留合法保護退出。
- 只撤銷進場單：處理增加曝險的未完成委託，不代表平倉。
- 預覽平倉所選部位：明確選取部位後核對範圍；仍須符合可退出數量與交易資格。
- 關閉介面：背景引擎及原已授權保護繼續運作，不會自動平倉。
- 檢查並關閉引擎：另行停止引擎；重開後須重新對帳及明確恢復新倉。

## 永豐權限開通後

到「設定」新增環境設定檔，分開登錄券商模擬與正式環境、帳戶參照、商品／日曆／費用／資格證據。
密鑰與憑證只使用明確的Windows Credential Manager引用，不貼到策略、診斷或AI。
保持唯讀與正式執行停用，先完成實際帳務、可賣量、行情與交割查詢，再安排券商模擬及至少五個實際交易日觀察。
本次沒有登入券商、讀取真憑證或操作真實資產；實際權限驗證仍須依 `BROKER_READINESS.md` 完成。

總覽、策略、市場、交易、績效與設定都會持續顯示目前環境及帳戶。未核對的資料會顯示未知，不能視為餘額或持倉為零。


## 更新行情與交付範圍

市場頁的「更新行情」可用滑鼠或Tab/空白鍵操作；F5快捷鍵保留。資料未核對或行情過期時顯示待核對，不視為零損益或零持倉。

三市場與持有政策可在本機合成資料完整模擬；永豐實際登入、資格、費用、交割、跨日觀察及正式執行仍待外部驗證。詳見[BROKER_READINESS.md](BROKER_READINESS.md)。獨立真人理解測試也尚待完成；本機工程通過不代表獲利或正式交易已通過。
