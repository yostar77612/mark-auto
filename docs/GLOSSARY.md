# MarkAuto 術語表

- **Backtest（回測）**：以固定歷史資料、策略與執行假設計算訊號、成交及帳本的研究評估；結果屬於該模型假設。
- **Paper（紙上交易）**：以 journal 為權威的離線合成帳戶與委託事件紀錄；不是券商模擬服務，也不代表真實成交。
- **Replay（重播）**：歷史行情按時間推進並驅動 Paper 的有界執行，綁定固定策略、資料及政策；不同於一般回測的全部成交語意。
- **Research eligibility（研究資格）**：資料與研究設定符合指定研究用途的准入條件；不是紙上資格或績效保證。
- **Paper eligibility（紙上資格）**：策略、資料、風控與帳務政策符合指定紙上執行用途的准入條件；不由研究資格自動推得。
- **OOS（樣本外）**：候選凍結後使用的一次性評估資料區段，不屬於反覆挑選候選的訓練或驗證資料。
- **Holdout（保留集）**：與訓練、驗證及 OOS 區段分離的最終保留評估資料；看過的資料不再是未見資料。
- **Consumed guard（已消耗防護）**：表示評估資料已被保留消耗、不能重新當作未見資料的持久狀態；同工作區重疊的保留區間亦屬已見。
- **Irreversible budget（不可逆預算）**：研究嘗試或供應者請求先保留並消耗的額度；失敗、中斷或結果未知不構成額度退還。
- **Strategy artifact（策略成品）**：供使用者持續辨識與管理的策略概念，可對應不同修訂；成品名稱不等於不可變內容身分，也不表示另有已驗證的版本管理服務。
- **Strategy revision（策略修訂）**：一份固定策略規格的不可變內容版本；修改內容形成另一修訂，既有結果仍歸屬原版本。
- **Live trading（實盤交易）**：向真實市場送出委託的交易活動；在本產品中永久停用（live trading permanently disabled）。
