# MarkAuto 術語表

- **Backtest（回測）**：以固定歷史資料、策略與執行假設計算訊號、成交及帳本的研究評估；結果屬於該模型假設。
- **Paper（紙上交易）**：以 journal 為權威的離線合成帳戶與委託事件紀錄；不是券商模擬服務，也不代表真實成交。
- **Replay（重播）**：歷史行情按時間推進並驅動 Paper 的有界執行，綁定固定策略、資料及政策；不同於一般回測的全部成交語意。
- **Research eligibility（研究資格）**：資料與研究設定符合指定研究用途的准入條件；不是紙上資格或績效保證。
- **Paper eligibility（紙上資格）**：策略、資料、風控與帳務政策符合指定紙上執行用途的准入條件；不由研究資格自動推得。
- **OOS（樣本外）**：候選凍結後使用的一次性評估資料區段，不屬於反覆挑選候選的訓練或驗證資料。
- **Holdout（保留集）**：與訓練、驗證及 OOS 區段分離的最終保留評估資料；看過的資料不再是未見資料。
- **Consumed guard（已消耗防護）**：表示評估資料已被保留消耗、不能重新當作未見資料的持久狀態；同工作區重疊的保留區間亦屬已見。
- **Irreversible budget（不可逆預算）**：研究嘗試或供應者請求先保留並消耗的額度；失敗、中斷或結果未知不構成額度退還。
- **Strategy artifact（策略成品）**：供使用者持續辨識與管理的策略概念，可對應不同修訂；成品名稱不等於不可變內容身分，也不表示另有已驗證的版本管理服務。
- **Strategy revision（策略修訂）**：一份固定策略規格的不可變內容版本；修改內容形成另一修訂，既有結果仍歸屬原版本。
- **Live trading（實盤交易）**：向真實市場送出委託的交易活動；在本產品中永久停用（live trading permanently disabled）。

- **Stop new orders（停止新委託）**：使用者確認停止或選擇僅觀察後，持久化手動委託鎖定；對帳、再次勾選同意、重播批次或重啟均不解除。既有部位、成交與委託仍保留，不自動平倉或撤單。
- **Cancel all pending（撤銷全部未成交）**：對帳戶快照中非 filled／cancelled／rejected 的委託逐筆請求撤銷，不平倉；鎖定時仍可使用，且不會解鎖。
- **Resume new orders（恢復新委託）**：透過「恢復新委託（需先對帳）」提交完整參考快照，先完成對帳再明確解除手動委託鎖定；未知委託或未解決的對帳狀態仍拒絕恢復，每次送單／重播仍須另行勾選同意；停止新委託本身保留既有掛單。
- **Expectancy（期望值）**：每個已平倉 FIFO 批次的平均淨損益，含打平批次；回測樣本的描述數字，不是未來報酬預測。
- **Payoff ratio（盈虧比）**：平均獲利除以平均虧損的正值；不同於總獲利除以總虧損的獲利因子。
- **Breakeven payoff ratio（打平盈虧比）**：虧損批次數除以獲利批次數，是此樣本勝負結構下的打平門檻。
- **Breakeven win rate（打平勝率）**：1 ÷（1 + 盈虧比）；含打平批次時不適用此二元公式。
- **Largest-win share（最大單筆獲利占比）**：最大單筆淨獲利除以所有正淨獲利之和。
- **Longest losing streak（最長連虧）**：依出場時間排序的最長連續虧損批次數；打平批次中斷連虧。
- **p value（p 值）**：假設沒有優勢時，出現至少這麼好結果的機率；不是策略無效的機率，也不保證未來獲利。
- **Confidence interval（信賴區間）**：以樣本重抽分布的百分位估計平均日報酬的不確定範圍；此處預設為 95%。
- **Required observations（所需樣本數）**：在單尾 alpha 0.05、power 0.8 假設下，以平均日報酬與樣本標準差估算的觀測天數，下限 30 天；不授予研究或紙上資格。
- **Centered bootstrap（平移重抽）**：每日報酬先扣除樣本平均，再以固定種子重抽，估計沒有優勢時的單尾 p 值。
