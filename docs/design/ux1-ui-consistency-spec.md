# UX-1 實作規格書：介面一致性整修

Status: SPEC FOR IMPLEMENTATION / NOT IMPLEMENTED. Verification: NOT RUN.
Audience: implementing agent (Codex). Owner decision dated 2026-11-01.
準則：[ui-guidelines.md](ui-guidelines.md)（本規格的所有要求以準則為準）。

## 0. 工作規則

沿用 [M2 規格](m2-sinopac-sim-auto-trading-spec.md) 第 0 節（完整測試、實際啟動檢查、字串與基準規則、CI 全綠、不合併到 main），
以及 [M1 規格](m1-implementation-spec.md) 第 0.1–0.3 節（不過度防禦、能併行就併行、自主決策不提問）。

**時程**：M2 第一輪全部合併後開始，可與 M2 第二輪併行。
**為避免衝突，不改**：策略頁與新增策略精靈（M2-4）、交易頁（M2-6 已處理）、設定頁的「永豐連線」區塊（M2-1）、
總覽頁版面（M2-5 與 M2-3 會依本準則第 2 節把總覽做成儀表板，見下方第 3 節）。

## 2. 驗收條件

- [ ] X1：每頁最多一個主要按鈕；所有停止、撤單、平倉、刪除、清除為危險樣式且需確認；`widgets.button()` 支援 `role`；無 inline 樣式。
- [ ] X2：頂部列四個標章正確反映狀態；無作業時不顯示取消；高度 ≤ 48px。
- [ ] X3：所有空表格有說明與可用的下一步按鈕。
- [ ] X4：1366×768 下預設欄位無橫向捲軸；欄位選擇可記住；數字格式與配色正確。
- [ ] X5、X6：版型符合準則第 2 節，長段落移入「?」。
- [ ] X7：三步引導依實際資料打勾並可前往；完成後隱藏，可在設定重新顯示。
- [ ] X8：v2 畫面掃描不含英文狀態代碼與 `+00:00` 時間（加測試）。
- [ ] 每個 PR 附準則第 10 節檢查清單與 1366×768、1920×1080 截圖。

## 3. 給 M2 第二輪的要求（寫給 M2-3、M2-5）

總覽頁由 M2-5（開盤前檢查清單、風控狀態）與 M2-3（執行狀態）改版時，依準則第 2 節做成儀表板：
重點卡片列（今日損益、啟用策略數、持倉數、待處理數、連線狀態）→ 開盤前檢查清單 → 策略清單（狀態、今日損益、最近訊號）
→ 最近成交與最近警示。首次對帳等例行流程用中性色（M2-6 第 7 點）。X7 的引導區塊放在最上方。
