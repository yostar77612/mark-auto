## 已知風險

- Paper 診斷與桌面 smoke 歷史偶發逾時，重跑成功不證明根因修復，期限不得放寬。
- 背景子程序成本、大型分鐘資料及長時間 Walk-forward 效能待改善。
- 真推論未驗證；研究 worker 的錯誤分類可觀測性有限。
- 安裝檔未簽章、舊 payload 累積與 main 保護外部限制仍在；不得繞過 SmartScreen。
- 非登入下載仍用預設 TLS 信任設定，目前資料來源正常不保證未來憑證鏈無風險。
- OOS 一次性消耗、不可逆預算、失敗封鎖與重啟對帳不變；停止新委託不會平倉。
